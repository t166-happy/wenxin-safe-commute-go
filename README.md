# 文欣安全通學 GO！V2.4 開放式 3D 大地圖原型

使用 TypeScript、Three.js、Vite。全部地理、時序與停靠尺寸為「教學示意」，尚待現地安全審核。

## 啟動及驗證

```powershell
npm install
npm run model:street
npm run dev
npm run lint
npm run typecheck
npm run test
npx playwright install chromium
npm run test:e2e
npm run build
npm run test:offline
npm run preview
```

開啟終端機顯示的本機網址，通常為 http://127.0.0.1:5173/ 。建置位於 dist，需 HTTP 伺服器開啟，不支援雙擊 HTML；預設僅監聽本機、不對外發布。

同一 Wi-Fi 實機試玩時，可自行執行 `npm run dev -- --host 0.0.0.0`，在手機開啟 `http://電腦區網IP:5173/`。本次沒有啟用區網監聽或修改防火牆。一般區網 HTTP 不提供 Service Worker 離線功能；離線保存需要 HTTPS 或 localhost。匿名 ID 已提供不依賴 randomUUID 的相容方式。

## 操作

1. 按「進入大地圖」，在同一張 3D 地圖自由走動；WASD／方向鍵／觸控方向盤移動。拖曳 3D 畫面轉鏡頭，滾輪調整遠近。
   地點文字只在角色靠近時浮現、離開後消失；鳥瞰時隱藏。上方「說明」開啟可捲動的遊戲說明，「暫停」停止角色及場景；所有對話窗都可按右上角 × 關閉。危險提示關閉後會回安全檢查點重試。
2. 靠近金色地點按「開始練習」，從地圖當下位置進入實作流程。地圖中的「輔助定位」可把角色帶到所選地點的安全等候區；步行方向也可在地圖選擇。練習中按畫面右上的「離開練習」，或在錯誤提示中按同名按鈕，即回到本次練習起點；已記錄的匿名安全操作仍保留。安親班接駁在獨立示意目的地完成後，按「回到本次起點大地圖」會用輔助定位返回，避免角色困在沒有步行連接的區域。
3. 走近練習中的金色圓圈，按 E 或互動鍵，也可點 3D 標記、車門、扶手與座椅。「前往標記」是單手替代走路，仍受相同碰撞及安全檢查，不自動互動。
4. 路口先實際停步、看左、看右，再等綠燈、轉彎車停讓及安全導護，沿斑馬線通行。
   正門與側門路口現在會在 3D 場景顯示小綠人和車用紅綠燈；車用紅燈時示意車輛停在斑馬線前。畫面上方的狀態條會提示「紅燈停等」「小綠人亮起」「車已停讓」；即使亮綠燈仍須完成停看與確認停讓。車輛靠站時也會顯示「行進中」及「已停穩」，手機提示不會蓋住方向與互動按鈕。
   正門小門與校園圍牆位於校園和人行道交界，人行道完整保留在圍牆與車道之間，可直接步行進校；四面圍牆僅在受控車行入口及兩處步行門留出開口。側門在復興北路一側的教學街廓，學生由外側街區沿人行道走來，經獨立的斑馬線、號誌與導護後，由上學開放的側門進校。側門圍牆旁是停車場，沒有建築；學生走分隔步道，不進入停車區。進入大地圖先顯示「四面圍牆」鳥瞰，按「回到角色」即可近距離行走；側門可在地圖選取「復興北路側門步行」前往。道路角度、停車格、號誌與門口尺寸仍是教學示意，待現勘確認。
5. 安親班接駁：**站在正門朝校外看**，左側是樹蔭／學生步道，中央是連續錐鏈，右側是小型接駁車。學生沿錐鏈內側的步道走到正門小門；集合 → 星星 01 核對 → 隊尾等候 → 成人確認 → 指定口 → 車門 → 02A → 拖曳／點按扣好帶扣 → 乘車 → 停穩解扣 → 依序下車 → 示意目的地交接。校車只在校門外獨立區域。
6. 家長汽車**上學送學**位於正門兩側短暫停靠示意區，學生從車內開始，不必在校門集合、核對車號或排隊上車。等家長停妥後解帶、看車門後方來車與自行車、選靠人行道側下車、關門並走到人行道，再依號誌及車流走斑馬線進校。家長確認安全後儘速駛離；遊戲不以操作速度計分，也不鼓勵匆忙開門。機車送學分在正門車道邊緣與復興北路側門口的獨立示意點，**機車不沿人行道行駛**；大地圖上可見前車先駛離、後車再入位。學生保持安全帽與坐穩，停穩後確認後方與行人再下車、走回步道，避免與兩側汽車短停混流。黃線實際臨停規則、時段與格位須依現場標誌和校方安排核實，遊戲不作真實停車指引。
7. 捷運從校外人行空間走到示意站，進站、刷卡、月台先下後上、搭乘三節普通車，再出站走回人行空間。A8 方向及站點配置仍為教學示意，尚待現地與營運資料核實。
8. 錐鏈不可穿越；危險行為立即停止，圖卡示範後回安全檢查點重試。禮貌是鼓勵，不能取代安全。
9. 設定可調速度、文字、語音、左右手、低畫質及減少動態；字幕持續顯示。教師「紀錄」可查看匿名事件、首次安全比例、示範及重試完成，並匯出 JSON／CSV 或清除。

車廂是獨立 3D 教學空間，沒有完整道路行駛模擬。其他運輸模組保留基本可玩流程，共享部分候車互動，未將全規格標為完成。

路燈、正門開放式滑門、側門弧形金屬門和波浪矮牆由本機 Blender 5.2 依 `scripts/build_street_assets.py` 原創產生，匯出為 `public/models/street_furniture.glb`。安裝 Blender 後可執行 `npm run model:street` 重新建模；Windows 上若 Blender 未加入 PATH，腳本會尋找 `C:\Program Files\Blender Foundation\Blender 5.2\blender.exe`。開發與遊玩不需要 Blender，正式建置使用已納入專案的 GLB。

## 保存與離線

只用隨機 sessionId 與 localStorage，最多最近 2000 筆；沒有姓名、學號、地址、GPS 或真實車牌。每次開啟建立新 session；完整旅程中斷續玩尚未實作。

build 自動產生靜態資源清單與 Service Worker。preview 首次下載並完成快取後可離線重載核心遊戲；dev 不註冊 Service Worker。實機手機快取政策仍待驗證。

測試見 docs/TEST_REPORT.md；階段見 docs/PROGRESS.md；來源授權見 docs/ASSETS_AND_SOURCES.md。校車／安親班以 V2.4 優先，安全以 V2.3 與錐鏈定案為底線。照片未直接放入遊戲，沒有公開學生影像或車牌。出口、道路、格位、管制、鏈條、無障礙及逃生配置均待校方核實。
