# 文欣安全通學 GO！V1.2 導護站與交通禮儀關卡

## 目的與範圍
把「導護站」納入步行、捷運出站步行、公車下車步行、校車及補習班車下車後進校等所有通學任務的共用節點。遊戲教育重點：安全停等、觀察號誌與車況、依照導護老師及志工的安全引導、尊重其他用路人及表達感謝。不得假定志工有法定警察交通指揮權；遇到衝突指引，以交通號誌及安全原則為準，必要時停下尋求協助。

## 3D 關卡互動與狀態機
- Approach: 角色走近導護站；提示減速並觀察導護志工／老師位置。
- Wait: 當停止牌或安全停等手勢出現，角色須在等待區停下；衝入路口觸發安全重置及動畫解說，禁止以碰撞事故作為娛樂。
- Assess: 允許玩家使用視角轉動／觀察鍵確認來車、斑馬線及號誌；評量「是否察看」與「是否安全」，不要只用計時獎懲。
- Proceed: 當號誌允許、交通已停讓且導護者示意安全通行時，玩家沿行穿線行走，不奔跑。
- Courtesy: 通行後可點選「謝謝」「點頭」「揮手」表情動作；完成可獲有禮徽章，但替代溝通方式等價，避免對不說話或行動不便學生扣分。
- Exit: 給予簡短語音及動畫回饋，記錄事件資料並回到通學主線。

## 隨機事件與教學反饋
1. 綠燈但轉彎車尚未停讓：維持停等並觀察；解說車輛停讓責任及行人留意環境的重要性。
2. 導護人員示意停等：角色停止並保持距離；解說導護工作與安全秩序。
3. 一名學生急跑想超車：玩家選擇放慢保持距離；不讓玩家推擠阻擋他人。
4. 輪椅或較慢行人使用通道：保持空間，不催促；說明通用設計、友善無障礙。
5. 下雨或視線受阻：先停、看清，再依號誌及引導通行；允許選擇安全替代路徑。

## 人本交通調查任務
學生透過點選熱點，標出等待空間不足、導護視線受遮蔽、人行道遭占用、穿越動線不連續等模擬問題；拖曳「改善等候區」「清理視線障礙」「行人動線導引」「無障礙通行」等圖卡，觀看改善前後示意。所有在地風險需現場查證後方可標示為文欣真實問題。

## 評量資料（僅匿名）
`{scenarioId, completed, safeStop, scannedTraffic, respectedSafeGuidance, crossedWithinMarking, courtesyAction, retries, improvementChoice}`。安全行動為必要達標項；禮儀採正向鼓勵，不能當安全行為的替代；不建立個別學生公開排名、不輸入學生姓名。

## SEL 與素養
自我管理：即使趕時間仍能安全停等；社會覺察：理解志工與其他行人的需求；人際關係技巧：適當表達感謝；負責任的決定：觀察風險並遵循合法安全引導。提供圖示／語音／文字三種提示，手機觸控目標建議至少44×44 CSS px。
