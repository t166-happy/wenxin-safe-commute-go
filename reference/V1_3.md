# 文欣安全通學 GO！— V1.3 交通車秩序與安全禮儀互動規格

## 定位與適用範圍
承接 V1.2 導護站及 V1.1 真實通學場景，新增交通車完整任務；涵蓋校車與補習班接駁車，資料與接送區均使用模擬資訊，真實停靠位置待學校查核後替換。遊戲必須可在電腦、平板、手機操作，學生不用鍵入長篇文字。

## 核心遊戲狀態機
`approach_stop -> wait_safe -> ordered_queue -> vehicle_stopped -> board_with_attendant -> locate_seat -> buckle -> riding -> request_help_if_needed -> vehicle_stopped_at_destination -> unbuckle -> orderly_exit -> thank_staff -> safe_exit_path -> results`

安全閘門：未完全停車不得開放上/下車；行車中不可解扣或離座；沒有正確入座及安全帶不能啟程；不得因跳過禮貌互動而妨礙安全通關。候車排序使用模擬號碼；學生要辨認隊伍而不需輸入姓名。

## 互動小遊戲與判分
1. 安全候車：拖曳自己角色至安全區域、避開車道。風險判斷、停等各 1 點。
2. 序號排隊：將角色依顯示的隨機模擬序號排隊，保持間距；秩序 2 點。
3. 等候開門：車速降為零、隨車人員確認後才能按上車；安全 2 點。
4. 找座位：在 3D 車廂內依 02-A 等座號選座，通道不可停留；定位 1 點。
5. 安全帶操作：拖曳插扣至扣環，確認扣合的視覺與音效；安全 2 點。
6. 行車情境：依虛擬事件點圖示選行為：安靜坐穩、扶持物品、向隨車人員求助、切勿打擾司機；決策 2 點。
7. 安全下車：車輛停妥、隨車人員引導、先解扣再依序離座下車；安全 2 點。
8. 禮貌互動：可選點頭、揮手、圖示對話「司機您好／謝謝司機／謝謝隨車老師」；提供正向徽章但不以口語能力評斷品德。
9. 漏乘／坐過站／留車演練：模擬如何向隨車人員求助；若被留車上，顯示依實際車型可用之喇叭／求救裝置／呼救操作，教學版不得假定每車具相同裝置。

## 回饋方式
不使用長文字問答：觸控拖放、角色移動、點擊、排序、按鈕及圖示。每次錯誤提供 3 至 8 秒動畫、口語解說與簡短關鍵句，允許重試；安全分數與禮儀徽章分開顯示，不以答題速度取代安全品質。

## 3D 資產
候車區路緣、交通車車身、前後車門（依實際車型配置）、座位編號、帶扣、司機 NPC、隨車人員 NPC、斑馬線、導護站與校門；卡通低多邊形，但路徑/站位/安全配置不得失真。車內角色、座位及號碼均為虛構資料。

## Codex 驗收條件
- 電腦鍵盤/滑鼠及手機平板觸控皆能完成全流程。
- 測試行車中按下「下車」或解扣無法成功，並收到正確解說。
- 測試序號排序、座位定位、正確帶扣及乘車互動事件。
- 下車後包含安全動線與導護站，對應原 V1.2。
- 正確操作與禮貌動作分開統計；支援匿名本機學習紀錄匯出。
- 不使用學生姓名、真實車牌、實際班級乘車名單及未查證的停靠點。
