# 驗收規範 / Definition of Done

## 一、功能測試
- [ ] 操作說明清楚顯示「可步行任務先進金色互動圈，再按動作」，車內座位起始任務有例外提示；輔助前往標記能讓角色走進圈內，停穩或號誌等安全條件未達時不誤示可操作。
- [ ] 接駁車、校車、公車與機捷乘車中可從 3D 車外視角看見輪子轉動、相對道路或軌道移動；停穩後輪子停止，手機畫面不裁切。
- [ ] 圖形實際使用 WebGL 3D，角色能在場景行走，車輛與 NPC 有行為。
- [ ] 步行：由鄰近街道出發，至少經過一處號誌／行穿線，能觀察、停等、穿越，過街後可向步道旁老師／志工問好並直接入校。
- [ ] 捷運：由 A7 或 A9 進站、選方向、候車、上車、至 A8 下車出站且接續步行；避免衝門。
- [ ] 機捷示意列車沿道路外側軌道進站，車身不壓入月台或穿越汽車道路；桌面與手機候車視角可看見學生、金圈與車門。停穩前不能走過安全線，出站後可接回人行道。
- [ ] 公車：從已核站點或明確示意站點候車、看車次、排隊、車內扶穩、按鈴、下車避開視線死角。
- [ ] 校車：候車順序、停穩上下車、編號入座、安全帶與隨車人員協助、下車致謝。
- [ ] 補習班接駁：確認車輛身分、指定安全等待區、上下車安全、乘車禮儀。
- [ ] 家長汽車送學：從車內開始，短暫停妥後解帶、觀察後方來車、選人行道側下車、關門後走人行道及斑馬線；不可要求校門集合或核對車號。放學接送異動求助另作擴充。
- [ ] 家長機車送學：正門與側門獨立點依序停妥，停穩前不得下車；觀察後方與行人、成人確認後安全下車，離開停靠點，避免與汽車臨停區混流。
- [ ] 老師／志工問好：無獨立導護站地點；過街後走近老師／志工會出現可關閉提醒，可按提醒問好並得到回應，走遠或問好後提醒消失；禮貌互動不替代停看、號誌與車輛停讓條件，也不阻擋入校。
- [ ] 正門與側門導護人物：老師與志工分站斑馬線兩端，小綠人及車輛停讓時走到行穿線中段兩側引導，學生中央通道保持暢通；車輛放行前退回人行道，校側老師能於學生過街後接受問好。站位仍標示教學示意。
- [ ] 人本設計師：點擊風險、選受影響用路人、拖放改善設施、比較改善前後、圖卡提案。
- [ ] 操作評量有可回放事件記錄與有意義短動畫/文字/語音回饋，失誤可重練。

## 二、安全與地理資料
- [ ] 未核實的出口、公車站、停車位置明確標示「示意」，校外路徑不得標成校方推薦。
- [ ] 號誌、行穿線、車輛方向、捷運站序具資料依據；駕駛停讓責任和兒童防禦觀察均有教學。
- [ ] 交通車行車時不得解安全帶或下車；發生安全錯誤立即暫停、提示及重置。
- [ ] 不收集學生姓名、學號、住家定位、車牌，匿名資料可清除。

## 三、跨裝置與無障礙
- [ ] Windows + Chrome/Edge 1366×768 可玩；平板 iPadOS Safari/Android Chrome 可觸控玩；iPhone Safari/Android Chrome 可通關。
- [ ] 最窄 360px 不裁切關鍵按鈕，觸控目標合理，支援減少動態效果、字幕和靜音。
- [ ] 低年級可完全不鍵入文字通關；錯誤解說可跳過或聽完重試。
- [ ] 使用語音之外另有字幕/圖標，對色盲者提供形狀或文字而非只靠紅綠顏色。

## 四、工程與文件
- [ ] `npm run dev` 可啟動；`npm run lint`, `npm run typecheck`, `npm run test`, `npm run build` 可執行並通過。
- [ ] 重要關卡狀態機至少有單元測試；有一套跨裝置 Playwright 基礎端對端測試或明確記錄限制。
- [ ] README、完成狀態、來源/授權清單、待核實地理資料、教學操作說明皆完整。
