# Codex 實作階段與交付排程（不預設日期）

## Phase 0 專案骨架
- 建立 Vite + TypeScript + Three.js、基礎測試、lint/typecheck/build、README、進度表及資料 Schema。
- 先以幾何形狀生成 Low-poly 學校、道路、人行道、行穿線、號誌，以及過街後步道旁的老師／志工 NPC，作為示意場景；不設獨立導護站。
- 驗收：desktop 與 mobile 瀏覽器可顯示 3D 地圖且可移動角色。

## Phase 1 可操作步行關卡（第一個真正交付）
- 校旁街道、行穿線、號誌、動態車輛、遮蔽物，以及正側門老師／志工依行人綠燈與車輛停讓走到行穿線中段引導、退回人行道，角色過街後向老師／志工問好的互動。
- 角色停看、轉鏡頭、過馬路及禮貌互動的操作事件評量，動畫+圖卡+重試。
- 驗收：至少一條 3D 步行上學連續路徑、一條放學任務，手機可觸控完整通關。

## Phase 2 運輸模組
- 機捷 A7/A9 → A8 站序、月台、上下車、A8 出站步行；鄰站公車候車、上下車、車廂互動；校車/補習班接駁候車排序、編號入座、安全帶、禮儀、下車；家長接送和轉乘鏈。
- 任務金色互動圈的可見範圍與實際操作半徑一致，單手輔助前往標記走到圈內後等玩家自行操作。車內安全操作保留，乘車時以 3D 車外視角同步呈現車體、轉動車輪與道路／軌道相對移動。
- 驗收：每種模式至少一條完整上學路線和一種常見失誤回饋；主要模式各有放學版本；不得退化成多選題。

## Phase 3 人本交通設計師
- 現況巡查、危險點蒐證、用路人角色卡、設施拖曳、模擬前後比較、方案圖卡提交與保存。
- 驗收：至少三類不同道路問題可透過玩家行動產出提案，且可以匯出匿名 JSON。

## Phase 4 教師與評鑑
- 難度/年段/通勤方式切換、關卡選擇、匿名事件總覽、CSV/JSON 匯出；教學展示模式、圖卡與語音設定。
- 驗收：教師能針對班級活動在單機展示完整情境與匿名統計；沒有學生姓名欄位。

## Phase 5 全面驗收與可部署建置
- 觸控、鍵盤、外接鍵盤、不同方向螢幕，降低效能模式，語音/字幕與可替代操作測試；安全性檢查，部署說明。
- 驗收：lint/typecheck/test/build 完整通過，附人工測試紀錄；手機可全程從首頁選關到結果；未核實站點清楚顯示示意。

## 任務完成回報格式
對每階段報告：（1）已開發功能（2）啟動/測試命令（3）執行結果與截圖（4）未實作功能（5）示意與待核資料（6）下一階段。
