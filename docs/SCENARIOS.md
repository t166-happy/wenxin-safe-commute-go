# 小遊戲關卡完整行為規格（所有學習以操作為主）
> 2026-11-05 使用者修正：移除獨立導護站地點；老師／志工位於過街後步道旁，學生可揮手問好並直接入校。過街條件仍是停看、小綠人、車輛停讓；問好不作安全通行門檻。以下舊稱「導護站」處以此修正為準。

## 全部場景共同要求
- 所有任務均須第三人稱角色移動或明確 3D 物件互動，遊戲中不可僅看圖片選題。
- 可步行的任務須走進地面金色互動圈再按 E／任務動作；汽車／機車座位起始任務依車內提示操作。「前往標記」自動導航到圈內但不自動互動或繞過安全判斷。停步、號誌、車輛停穩與成人放行條件未成立時，提示須說明仍需等待。
- 乘車中的接駁車、校車、公車和機捷要有可見的車外 3D 車體與車輪滾動視角；捷運使用軌道示意，停車後輪子停止。
- 每局含：安全預備 → 線索觀察 → 行動 → 即時回饋 → 再練習 → 兩項以上能力證據。
- 乘車時「停穩才能上下」是狀態閘門；不得用禮貌徽章抵消安全違規。
- 司機駕駛時不能為了遊戲禮儀而分心聊天；謝謝司機安排在停車後、下車時。

### WALK-01 步行到校（核心垂直切片）
起點：文昌五街等校旁經確認或標示示意的巷口。玩家依人行空間行走，靠近路口先減速，透過移動視角觀察行人號誌、右左轉車輛及停車遮蔽。行人小綠人與車輛停讓共同決定通行條件，禁止紅燈闖入。駕駛有停讓行人責任；不要暗示行人綠燈必然零風險。
互動：「行走」「停步」「轉鏡頭觀察」「等候」「安全穿越」「過街後向老師／志工問好」。失誤：未觀察轉彎車、穿越未劃設處、靠近車道邊追逐。完成：安全進校。安全操作為主要條件，問好可選。
### WALK-02 放學步行返家
由校門出發，跨兩段路口，加入雨天/傍晚/停車遮蔽；分辨適合等候與回頭路，若導航引導至不存在的穿越點，要能改走合法路線。
### MRT-01 鄰站搭機捷到 A8
起點可選 A7 體育大學站或 A9 林口站（屬鄰站關係）；根據列車到 A8 方向選月台，再透過閘門、樓梯或電梯到候車處；避開月台邊緣、排隊先下後上，車門關閉提示時不衝門。上車後抓扶手或入座，到 A8 下車、出站、步行往文欣。真實出口和步行動線現勘前「示意」。
互動：指示牌圖卡 → 點閘門 → 站點方向辨識 → 走到排隊區 → 等車停妥 → 讓出車門 → 上車 → 扶穩 → 下車 → 出站。可設無障礙電梯替代路徑。搭電扶梯時站穩握扶手，不在電扶梯上奔跑。
### MRT-02 放學搭捷運
從文欣步行至 A8、依目的站選不同方向的月台；練習站名辨認、轉乘動線、候車禮儀、需要協助如何尋找站務人員；如錯過車以等下一班為正解。
### BUS-01 鄰站搭公車到校
公車站牌與路線使用 `verificationStatus`：未核實時顯示「示意站點／示意路線」，不得寫成現況。學生走到安全候車區→確認公車方向、站牌→停穩排隊→車內扶好/入座→欲下車先按鈴→停穩再下車→不可從大型車前後方突然穿越→沿安全動線入校。
互動：拖移路線圖卡 → 列隊 → 刷卡/感應 → 點扶手或座位 → 按鈴 → 下車 → 遠離車體遮擋後到行穿線。
### BUS-02 放學搭公車
由校門走到正確站點；遇到多輛公車先確認路線；若未停妥不追車；擁擠車廂使用合宜扶手、留意背包不妨礙旁人及禮讓有需要者。
### SCHOOL-01 校車候車、入座與到校
使用示意社區候車點；先確認集合位置/編隊序號（模擬），依序排隊不插隊→車停妥、隨車人員許可→依序上車→找到虛構座位編號（例如 02A）→入座繫安全帶→車行時維持坐姿→到站停妥才解扣、依序下車→向司機及隨車人員致意→走指定安全動線入校。
互動：排列隊伍角色/站位 → 確認車輛停靠 → 走入車廂 → 3D 座位點選 → 拖曳安全帶扣入 → 接受停車後的口頭/圖卡回饋。
### SCHOOL-02 校車放學返家及異常應變
候車秩序、安全確認、乘車中不干擾司機；若不舒服應向隨車人員求助；下車確認物品與安全位置。若被單獨留在車內，依情境尋找實際可用的喇叭、緊急求救裝置或求救通路，不假設所有車配備同樣裝置；教導大聲求救與可見位置求援，不隱藏角落。
### SHUTTLE-01 補習班接駁
校門→指定安全集合點→按經校方確認的接送識別或隨車人員引導辨認車輛（遊戲虛構車輛身份）→依序候車/上車/入座/繫安全帶→停穩下車→與人員禮貌互動；若接送不符應返回指定成人協助，不上陌生車。
### PARENT-01 家長接送
上學汽車送學（2026-11-04 使用者現地補充優先）：學生已乘坐家長汽車抵達正門兩側示意短停區，**不在校門集合、核對車號或排隊上車**。家長依現場規定短暫停妥，不占用行人通道，也不因趕時間催促學生冒險開門。學生等車完全停妥 → 解安全帶 → 觀察車門後方汽機車、自行車與行人 → 確認靠人行道的安全側 → 下車並關好車門 → 走上人行道到斑馬線 → 停看、等號誌與車輛停讓，過馬路進校。家長在確認安全後儘速駛離，避免長時間佔用路側。放學接送異動的求助情境保留為後續獨立擴充，不套用此上學送學流程。實際可停時段與格位仍待現地與校方核定。
### SCOOTER-01 家長機車送學
學生已在家長機車上，依序抵達正門口或復興北路側門口的獨立示意停靠點，不與正門兩側汽車短停區混用。前車離開後依序停妥；乘客戴好安全帽、坐穩並放穩雙腳，機車移動中不得下車。停妥後觀察後方車輛與行人，由成人確認人行道側安全，盡快下車並走回步道；機車依序駛離。此處「盡快」指不在停靠點逗留，**不以速度計分，也不能省略觀察或趁車未停妥下車**。兩處實際停靠位置與管制仍待校方確認。
### WALK-GREET 過街後向老師／志工問好（步行流程內）
正門與側門不另設導護站練習點。學生先停看、確認行人號誌與車輛停讓，安全走完斑馬線；走近步道旁老師／志工時出現可關閉的問好提醒，可按提醒直接揮手問好，角色與老師／志工互相回應，並直接沿步道入校。走遠或完成問好後提醒消失。問好是可選禮貌操作，不替代過街條件，也不要求停下再次確認。
正門與側門各有一位老師在校側、一位志工在街區側。小綠人亮起且車輛停讓時，兩人從安全等候處走到斑馬線中段兩側揮手引導，不占用學生中央通道；行人綠燈結束前退回兩端，校側老師也會隨學生穿越進度返回，讓學生在對側安全步道問好。成人引導不取代學生確認號誌與車輛停讓。此為教學示意，實際值勤位置與做法待校方核定。
### TRANSFER-01 多模式轉乘
「捷運→步行」「公車→步行」「校車→步行入校」「放學→接駁車」四種鏈；任務中保留上一段完成的安全狀態。強調車站出口、站牌、路口的連續動線與行人空間。
### HUMAN-01 人本交通觀察與改善
探索 3D 場景點擊危險點（車輛遮擋、候車空間狹窄、接送區行人混流、無障礙通行不便）→從圖卡標記風險與受影響者→拖曳候車分區、路口視距改善、行穿線/人行空間等候選措施→遊戲模擬前後行人與車流→分辨有效措施與待專業審查的改造；可用圖卡完成提案，文字選填。
